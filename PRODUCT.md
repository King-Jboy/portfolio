# Product Context: Maduabuna Josiah Portfolio

## Purpose & Positioning
Personal portfolio and technical presence for Maduabuna Josiah, an 18-year-old 200-level Cybersecurity undergraduate student at Babcock University, Nigeria.

The site communicates:
- An authentic, technically curious student exploring how digital systems, networks, and software behave, break, and defend.
- Primary interests: Ethical Hacking, Penetration Testing, Malware Analysis.
- Secondary exploration: Network Security, Web Security, Digital Forensics, Cloud Security, Cryptography, OSINT, Threat Intelligence, Incident Response, Security Research.
- Foundation: Linux daily operating environment and Python automation scripting.
- Software engineering capability: `kingjboy-claude-code`, an extensive personal fork of Free Claude Code demonstrating multi-agent orchestration, credential pooling, and provider switching (clearly differentiated from security research).
- Verified Credential: NVIDIA Deep Learning Institute — Certification.
- Authentic stage: Early in professional journey, zero fabricated achievements, clients, awards, or fake skill percentages.

## Audience
- Cybersecurity professionals, security researchers, and prospective internship/mentorship directors.
- Technical peers, academic colleagues, and student collaborators.

## Design Mode
- **Experience Mode**: Portfolio surface where the craft and substance speak immediately. The interface is calm, quiet, and recedes, allowing high-craft typography, authentic technical writing, and a mathematical 3D system topology to establish authority.

## Strict Aesthetic Constraints
- Tone: Intelligent, curious, calm, precise, technical, experimental, restrained.
- Absolutely NO stereotypical hacker junk: No matrix rain, no neon green spam, no fake terminal spam, no skulls, no glitch abuse.
- Absolutely NO AI templates: No nested cards, no fake eyebrows or kickers above headings, no artificial section numbering, no monospace-as-costume.
- Palette: Deep tinted obsidian (`#07080a`), high-contrast off-white type (`#f4f4f5`), calibrated steel neutral (`#94a3b8`), and surgical cyan/ice accents used solely for real data points and active interactions.
